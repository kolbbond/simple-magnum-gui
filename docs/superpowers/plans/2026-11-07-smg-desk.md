# smg-desk: Desktop Data Layer Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show live system data on the desktop, built from smg. `smg-desk` is a compact panel of sparklines, gauges and text that runs as a floating click-through overlay and, in a later phase, on the Wayland *background* layer, between the wallpaper and the windows. It replaces the stow `shud` desktop HUD (`defcon/hypr-config/desktop-hud.ini`). smg becomes the single source for this kind of app: `smg-sysinfo` and `smg-desk` read the same data module.

**Architecture:** There are three layers, and each one is useful on its own.

```
  smg-desk (examples/desk.cpp)        config file -> panels; --layer, --output
     |
  smg::sys  (include/Sys.hh)          samplers + history; shared with smg-sysinfo
     |
  GuiBase + WindowPlatform            transparent/click-through window, low-power redraw,
                                      optional layer-shell presenter (background mode)
```

**Background mode without leaving SDL2.** SDL2 cannot give a window a layer-shell role, because SDL has already made it an `xdg_toplevel`. Background mode therefore renders through the existing hidden or off-screen path (`GuiConfig::hidden`, `grab()`), then copies each frame into a `wl_shm` buffer attached to a `zwlr_layer_surface_v1` that smg owns. That surface is on a private event queue on SDL's `wl_display`, which is the same pattern as `compositor()` in `WindowPlatform.cpp`. At 1–2 fps the CPU copy costs nothing. The background layer receives no input, so click-through comes for free. A zero-copy `wl_egl_window` presenter is possible later if the panel ever needs animation.

**Prior art to reuse:**
- `examples/sysinfo.cpp`: the samplers (`Monitor`, `Snapshot`, `ProcessSampler`, history).
- `examples/overlay.cpp`: the transparent, click-through, SIGUSR1-toggle pattern.
- `kolbbond/shud` (private, archived at `~/archive/src-bak/shud`): `src/wayland_window.cpp` and `protocols/wlr-layer-shell-unstable-v1.xml`, plus its `wayland-scanner` CMake recipe. Today it uses `ZWLR_LAYER_SHELL_V1_LAYER_OVERLAY`. The background layer is a one-enum change.
- `kolbbond/stow`: `shud`'s ini dashboard (`[grid]` / `[cell]`, `cmd` sources) as the model for the desk config.

## Global Constraints

The constraints are the same as in `2026-06-28-plotting-api.md`:
- Use the `build/` dir and build single-core (`-j1`).
- No `auto` and no `using`.
- Laconic comments.
- No `Co-Authored-By` trailers.
- Commit subjects are topic-prefixed.
- Pure logic gets headless `unit` tests. Anything needing a display gets self-terminating `gui` tests.

Two Linux-specific constraints:
- Every Hyprland IPC call goes through `WindowPlatform.cpp`. Since **Hyprland 0.57**, `dispatch` takes Lua (`hl.dsp.*`), and the old hyprlang syntax is an error. Probe for Lua once, fall back to legacy, and check every reply in a `[[BATCH]]`.
- Sampler readers take a filesystem root (`/` by default), so tests can point them at fixture trees under `test/fixtures/sys/`.

## Phase 4: Background layer

- [ ] Vendor `wlr-layer-shell-unstable-v1.xml` (and `xdg-shell.xml`, which it references) and generate client code with `wayland-scanner` behind `SMG_HAVE_WAYLAND`.
- [ ] `detail::LayerPresenter`: bind `zwlr_layer_shell_v1`, `wl_shm` and `wl_output` (v4, for `name`) on a private queue. Create the layer surface with the layer, output, anchor, margin and size. Keep `keyboard_interactivity = none` and an exclusive zone of -1, so the panel doesn't push windows.
- [ ] Add `GuiConfig::layer` (`none|background|bottom|top|overlay`), plus `output`, `anchor` and `margin`. A non-`none` layer implies hidden rendering. `drawEnd` hands `grab()` to the presenter. Present only when the frame's content changed, and keep two buffers so a buffer the compositor still holds is never written.
- [ ] Verify early that SDL's hidden window keeps a usable GL context on Wayland. This is the main risk. The fallback is a small surfaceless or pbuffer EGL context.
- [ ] `smg-desk --layer background --output DP-3` becomes the defcon default.

## Risks

| Risk | Mitigation |
|---|---|
| A hidden SDL window loses its GL context or swaps on Wayland | Phase 4 spike first. Fallback: an EGL pbuffer context that shares nothing with SDL |
| A Hyprland IPC reply of "ok" doesn't prove the dispatch took effect | Verify by querying the client state (`j/clients`), as the probes for Phase 1 did |
| NVML is missing on non-NVIDIA hosts or Windows | `dlopen` and degrade to empty fields. Never a link dependency |
| `-j1` builds are slow from a clean tree | Build only the touched targets (`--target overlay`, `--target desk`) |
