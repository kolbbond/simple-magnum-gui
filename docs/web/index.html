simple-magnum-gui

Magnum + Dear ImGui, compiled to WebAssembly. Needs a WebGL 2 browser.

  • Scene panelOrbit/pan/zoom a 3D scene; tick "Section" to cut it with a clip plane.
  • Sprite panelCamera-facing billboard sprites in a 3D scene.
  • GuiBaseThe bare application shell: ImGui windows and plotting.
